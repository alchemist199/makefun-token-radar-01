Implied value is this radar's own claim, built from the snapshot's TVL, 7-day growth, age with no token, and chain breadth. It never predicts whether or when a token is issued.

How the value is built

implied value = TVL × peer multiple × growth × maturity × breadth

  • Peer multiple — the median market-cap / TVL ratio of live-token protocols in the same category (at least 3 priced peers, else the overall median ). The market's own yardstick, recomputed from the snapshot on every run.
  • Growth — the protocol's 7-day TVL change, clamped to −60%..+120% and half-weighted.
  • Maturity — 0.60 to 1.00 by days listed with no token (full weight at 3 years; unknown age counts as 365 days).
  • Breadth — +2% per extra chain, up to +10%.

Live-token protocols are kept apart in the Live view below: they already trade, so the board shows the market's own value for them, never a model. A protocol is called pre-token only because its DefiLlama record carries no token — never that it has none.
